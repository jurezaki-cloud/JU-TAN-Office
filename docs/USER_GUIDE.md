# Uporabniški vodič — JU-TAN Office Enterprise 1.0.0 GOLD

## Zagon

Namestite `JU-TAN-Office-Setup.exe` ali odprite prenosno mapo in zaženite `JU-TAN-Office.exe`.
Ob prvem zagonu vnesite podatke podjetja. Geslo je priporočeno.

## Glavni moduli

| Modul | Namen |
| --- | --- |
| Dashboard | Pregled |
| Stranke | CRM evidenca strank |
| Artikli | Katalog |
| Ponudbe | Predračuni |
| Naročila | Prodajna naročila |
| Računi | Izdaja in PDF |
| Plačila | Likvidacija |
| Skladišče | Zaloga in premiki |
| Dobavitelji / Nabava | Nakup |
| Dokumenti | DMS |
| CRM | Lead in pipeline |
| Poročila | Excel / PDF |
| Automation | Pravila |
| Nastavitve | Videz, backup, varnost |

## Tipičen tok

Lead → stranka → ponudba → naročilo → dobavnica → račun → plačilo → poročilo.

## Iskanje in izvoz

Iskalnik v orodni vrstici filtrira trenutni seznam. Excel in PDF sta v orodni vrstici modulov.

## Varnostna kopija

Nastavitve → Backup Database. Obnova: Restore Database, nato ponovni zagon.
